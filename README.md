👋 About Me

Hi, I'm Youssef Albaz, an aspiring AI Engineer with a strong interest in technology, science, and the future of computing.

I'm starting this journey from the fundamentals of computer science, with a long-term goal of understanding how intelligent systems work and learning how to build AI models from the ground up.

I believe that real engineering begins with understanding the fundamentals, asking questions, experimenting, and learning from mistakes.

This GitHub profile is where I document that journey — from my first computer science concepts and programming exercises to increasingly challenging engineering projects.

- 🧠 Build a deep understanding of computer science and artificial intelligence.
- 💻 Learn programming through practical implementation.
- 📐 Develop the mathematical foundations required for AI.

- 🏗️ Build increasingly complex projects and document their design.

💡 My Engineering Principles

- Fundamentals first: Understand the underlying principles before relying on abstractions.
- Learn by building: Turn theoretical knowledge into practical work.
- Explain, don't memorize: Be able to explain why something works.
- Measure real progress: Focus on understanding, code quality, and project outcomes.
- Document honestly: Clearly distinguish completed work from plans and experiments.
- Keep improving: Treat mistakes and failed experiments as opportunities to learn.
- Share knowledge: Make learning useful to others whenever possible.
